# Viola source release

The public source distribution lives in [`SOURCE/`](SOURCE/README.md).

- [Install and run from source](SOURCE/docs/INSTALLATION.md)
- [Verify the source and dependency inventory](SOURCE/docs/VERIFYING.md)
- [Contribute](SOURCE/CONTRIBUTING.md)
- [Report a security issue](.github/SECURITY.md)

The root `PUBLIC_METADATA/` directory binds the released source tree and records
dependency/provenance metadata. Hosted Viola services, production operations, customer
data, and private commercial components are not included in this repository.
