# Contributing

Use a separate branch and keep each change focused on an observable behavior.
Include reproduction steps and regression coverage for fixes. Follow existing
Python and React conventions, preserve authentication and consent protections,
and run the checks in [VERIFYING.md](docs/VERIFYING.md).

Contribute only material you have the right to distribute. Identify third-party
origins, versions, modifications and license terms. Original contributions are
submitted under the project's Apache-2.0 terms unless explicitly stated otherwise;
third-party material retains its own terms. Do not submit copied proprietary code,
credentials, personal recordings, production data or private company documents.

Use respectful, specific issue reports and reviews. Describe expected behavior,
actual behavior, platform and steps to reproduce. Share only sanitized logs.
Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
