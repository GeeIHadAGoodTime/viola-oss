# Wake word detection
# #4786: openwakeword IS required. Ground-truthed against the actual shipped
# violawake_data/trained_models/temporal_cnn.onnx via onnxruntime: its ONNX
# graph declares input "embeddings" shape (batch, 9, 96) -- the OpenWakeWord
# embedding shape, not a raw mel-spectrogram -- so violawake/engine.py's
# ViolaWake._load_model() always routes it through _load_onnx_mlp(), which
# constructs openwakeword.utils.AudioFeatures to turn raw audio into those
# embeddings before the classifier runs. Without openwakeword installed this
# raises ImportError the moment the wake engine loads, which is what happens
# on every Linux install (this entry was previously excluded on a stale
# comment claiming the production model was "mel/CNN" and openwakeword-free
# -- that premise predates whatever retrained/replaced temporal_cnn.onnx with
# this embedding-based architecture, and nobody updated this file to match).
# pyaudio IS required: voice/wake_detector/violawake_listener.py imports it at
# module top, so the wake path fails to import without it. Needs system
# portaudio19-dev / libportaudio2 (installed by install.sh).

# Secret Service backend for `keyring` on Linux. WITHOUT these two, keyring's

# silently kills BOTH the credential store (utils/secure_credentials.py) and the

# build_appimage.sh verifies they landed in the frozen bundle. They must ALSO be
# added to viola.spec hiddenimports (L3-owned) for PyInstaller to collect them;
# until then the build_appimage.sh require_find will fail closed rather than ship
# a keyring-dead bundle.
